# Finance Tracker with AI Analyst ✨

Современное приложение для учета личных финансов с интеграцией Искусственного Интеллекта (Google Gemini).

## 🚀 Последние обновления

### 🤖 AI-Интеграция
- **Smart Input:** Умный ввод транзакций свободным текстом (например, *"купил продукты на 150к вчера в 15:00"*). ИИ автоматически определяет категорию, дату, время и сумму.
- **AI-Аналитик:** Генерация глубоких финансовых отчетов. ИИ анализирует ваши траты, находит аномалии и дает персонализированные советы.
- **Персонализация:** Возможность задать ИИ свои финансовые стратегии (например, 15/25/50/10) через настройки.
- **Экспорт:** Скачивание AI-отчетов в формате `.txt` для личного архива.

### 🔐 Безопасность и Приватность
- **BYOK (Bring Your Own Key):** Ваш Gemini API ключ хранится только в локальной памяти браузера и никогда не передается на сервер.
- **Очистка данных:** Проведен полный аудит безопасности. Все персональные данные (номера карт и т.д.) удалены из кода.
- **Защита Firebase:** Внедрены проверки владельца (`userId`) для всех операций с базой данных.
- **Git Protection:** Конфиденциальные файлы (`.env`, отчеты, таблицы) автоматически исключаются из репозитория через `.gitignore`.

## 🛠 Технологии
- **Frontend:** React + TypeScript + Vite
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **AI:** Google Gemini API (Gemini 2.5 Flash)
- **Icons:** Lucide-React
- **Styling:** CSS3 (Modern Glassmorphism Design)

## 📦 Установка и запуск

1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`.
3. Создайте файл `.env` и добавьте ваши Firebase ключи (см. `.env.example`).
4. Запустите проект: `npm run dev`.
