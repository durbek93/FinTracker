# 💰 Личный Финансовый Трекер (Finance Tracker) с AI-Аналитиком ✨

Современное веб-приложение для учета личных финансов, созданное с фокусом на удобство использования, красивый интерфейс (glassmorphism), безопасность и интеграцию с Искусственным Интеллектом (Google Gemini). Позволяет детально отслеживать доходы, расходы, переводы между счетами, анализировать финансовую статистику и получать персонализированные советы от ИИ.

## ✨ Основные возможности

### 📈 Финансовый учет
- **Управление счетами:** Ведение нескольких счетов в разных валютах (например, UZS и USD).
- **Мультивалютность:** Корректный учет конвертаций, кросс-валютных переводов и расходов с точным расчетом затраченных средств.
- **Подробная аналитика:** Визуализация расходов и доходов, фильтрация по датам и категориям. Раздельный учет стандартных трат и расходов в конвертированной валюте.
- **Гибкие транзакции:** Поддержка дробных значений, точного времени, добавления комментариев.
- **Умное скрытие из статистики:** Возможность исключить определенные транзакции (quick-toggle) или целые счета из общей статистики.
- **Адаптивный UI/UX:** Темная и светлая темы, плавные микро-анимации, поддержка безопасных зон на мобильных устройствах (safe-area insets), современный Glassmorphism дизайн.

### 🤖 AI-Интеграция и Telegram-бот
- **Smart Input (Умный ввод):** Ввод транзакций свободным текстом (например, *"купил продукты на 150к вчера в 15:00"*). ИИ автоматически определяет категорию, дату, время и сумму.
- **Голосовое управление через Telegram-бот:** Возможность отправлять в бот голосовые сообщения с расходами. Бот автоматически скачивает аудиозапись, отправляет её в Gemini 2.5 Flash (через мультимодальный интерфейс), распознает финансовые параметры и вносит трату в базу данных.
- **AI-Аналитик и озвучка отчетов (Text-to-Speech):** Генерация глубоких финансовых отчетов по запросу в Telegram-боте. ИИ анализирует ваши траты, находит аномалии и формирует отчет. Дополнительно интегрирована автоматическая озвучка отчетов через Google Cloud Text-to-Speech API в родной для Telegram формат голосовых сообщений `OGG_OPUS`.
- **Персонализация:** Возможность задать ИИ свои финансовые стратегии (например, 15/25/50/10) через настройки. Все настройки пользователя синхронизируются с облачной коллекцией `userSettings` в Firestore, благодаря чему бот выдает советы с учетом вашей персональной стратегии.
- **Связывание аккаунтов Telegram:** Безопасное связывание Telegram-аккаунта с базой данных приложения с помощью временных кодов привязки (linkCodes) и бесшовная авторизация через Telegram Custom Token в Telegram WebApp.
- **Экспорт:** Скачивание AI-отчетов в формате `.txt` для личного архива.

### 🔐 Безопасность и Приватность
- **BYOK (Bring Your Own Key):** Ваш Gemini API ключ хранится только в локальной памяти браузера и никогда не передается на сторонние сервера.
- **Безопасная авторизация:** Интеграция с Firebase Auth. Поддержка входа по Email/Паролю и по номеру телефона (СМС). Возможность привязки нескольких способов входа к одному аккаунту.
- **Защита Firebase:** Внедрены строгие правила безопасности Firestore (Firebase Security Rules) с проверками владельца (`userId`) для всех операций с базой данных.
- **Очистка данных:** Проведен полный аудит безопасности. Все персональные данные (номера карт и т.д.) удалены из кода.
- **Git Protection:** Конфиденциальные файлы (`.env`, отчеты, таблицы) автоматически исключаются из репозитория через `.gitignore`.

## 🚀 Последние обновления и изменения

- **Переход на полноценного ИИ-агента с поддержкой динамических периодов:**
  - **Динамический анализ периодов:** ИИ-агент теперь распознает относительные временные диапазоны (например, «за последние 5 дней», «за прошлую неделю») и выполняет фильтрацию транзакций по указанным датам вместо жестко зашитого анализа за весь месяц.
  - **Точный расчет фактического баланса:** Внедрен расчет реального баланса по всем счетам пользователя на основе всех транзакций. ИИ теперь четко разграничивает месячные накопления (доходы минус расходы за период) и реальный текущий остаток на счетах.
  - **Упоминание стратегии в отчете:** Добавлено обязательное указание периода анализа и активной финансовой стратегии пользователя в заголовке отчета ИИ.
  - **Устранение зависаний Telegram-бота:** Длина чанков при отправке отчетов снижена до 3000 символов с HTML-разметкой, лимит TTS уменьшен до 1500 символов (для стабильной работы на кириллице с Google Cloud TTS), и добавлена отказоустойчивая обработка ошибок (бот больше не зависает в бесконечном «Думаю...» при сбоях Telegram API).
- **Голосовая озвучка отчетов AI-Аналитика в Telegram-боте:** Интегрирован синтез речи Google Cloud Text-to-Speech для автоматического создания голосовой версии финансового отчета в формате `OGG_OPUS` с использованием Wavenet голосов. Разработан модуль очистки Markdown разметки (`functions/src/tts.ts`), исключающий произношение служебных символов и эмодзи.
- **Облачная синхронизация стратегий пользователя:** Внедрена Firestore-коллекция `userSettings` и соответствующий хук `useFinancialStrategy.ts` в веб-приложении для сохранения стратегий и личных инструкций. Добавлены правила безопасности в `firestore.rules`. Бот считывает эти настройки для адаптации финансовых советов.
- **Голосовое управление и интеграция с Telegram-ботом:** Добавлен функционал распознавания голосовых трат через Telegram. Интегрировано скачивание голосовых заметок и их прямая обработка через Gemini 2.5 Flash без сторонних Speech-to-Text сервисов.
- **Умный учет долгов:** В настройки категорий добавлена опция «Не учитывать в статистике (долги, возвраты)». Это позволяет корректно фиксировать выдачу и возврат долгов, чтобы они отражались на реальном балансе счетов, но не искажали общую аналитику доходов и расходов.
- **Улучшения UI/UX Фильтров:** Окно выбора дат в разделе "Статистика" переведено в формат выпадающего меню-аккордеона с улучшенной читаемостью текста и функцией быстрого выбора целого месяца. В "Истории" добавлено выпадающее меню для быстрой фильтрации по категориям прямо рядом со строкой поиска.
- **Исправление багов с датами:** Устранена возможность добавлять транзакции "будущей" датой. Также исправлена критическая ошибка, когда ручной ввод несуществующей даты (например, 31.04) ломал фильтры в Истории и Статистике.
- **Поиск и Фильтрация:** В истории транзакций теперь доступен поиск по заметкам и категориям. В раздел "Статистика" добавлен выбор произвольного периода (С/По) с автоматическим обнулением счетчиков каждый месяц.
- **Улучшения UX:** Окно создания/редактирования категорий переведено в классический модальный вид по центру экрана для удобства при большом количестве категорий.
- **Безопасность и подготовка к GitHub:** Ключи конфигурации Firebase вынесены в переменные окружения (`.env`), проект полностью подготовлен для публичного репозитория на GitHub. Настроена Firebase SMS-авторизация и логика связывания аккаунтов.

## 📦 Установка и запуск (для разработчиков)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/tracker-app.git
   ```
2. **Перейдите в папку проекта:**
   ```bash
   cd tracker-app
   ```
3. **Установите зависимости:**
   ```bash
   npm install
   ```
4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне папки `tracker-app` (или переименуйте `.env.example`) и добавьте ваши ключи Firebase:
   ```env
   VITE_FIREBASE_API_KEY=ваш_ключ
   VITE_FIREBASE_AUTH_DOMAIN=ваш_домен
   VITE_FIREBASE_PROJECT_ID=ваш_id_проекта
   VITE_FIREBASE_STORAGE_BUCKET=ваш_bucket
   VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_sender_id
   VITE_FIREBASE_APP_ID=ваш_app_id
   ```
5. **Запустите сервер разработки:**
   ```bash
   npm run dev
   ```
