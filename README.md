# 💰 Личный Финансовый Трекер (Finance Tracker) с AI-Аналитиком ✨

Современное веб-приложение для учета личных финансов (PWA), созданное с фокусом на удобство использования, эстетичный интерфейс (Glassmorphism), безопасность, автономность и интеграцию с Искусственным Интеллектом (Google Gemini). 

Позволяет детально отслеживать доходы, расходы, переводы между счетами, вести финансовые цели и подписки, управлять займами и долгами с автопарсингом, анализировать финансовую статистику и получать персонализированные советы от ИИ.

---

## ✨ Основные возможности (Версия 2.0)

### 📈 1. Финансовый учет и Мультивалютность
- **Управление счетами:** Ведение счетов в разных валютах (UZS и USD) с защитой от случайного удаления ключевых счетов.
- **Официальный курс ЦБ РУз (CBU.uz):** Автоматическая загрузка актуального курса доллара Центрального банка Узбекистана в 1 клик для точной конвертации.
- **Кросс-валютные переводы:** Учет конвертаций между счетами и учет покупки валюты как расхода.
- **Быстрые шаблоны (Quick Templates):** Сохранение часто повторяющихся платежей для создания операции в одно касание.
- **Хэштеги (`#tags`):** Добавление произвольных тегов к операциям (`#отпуск`, `#ремонт`, `#авто`) для гибкой фильтрации и группировки.
- **Лимиты и Бюджеты по категориям:** Настройка месячных лимитов (`monthlyBudgetUZS`) с наглядными прогресс-барами и подсветкой перерасхода на Главной странице.
- **Скрытие из статистики:** Возможность исключить определенные операции или целые категории из общей аналитики (например, для нерегулярных крупных переводов).

### 🤝 2. Интеллектуальный учет Долгов и Займов
- **Автопарсинг операций в Долги:** Система автоматически распознает долговые транзакции и формирует карточки долгов с выводом их на Главную страницу:
  - 📤 **«Одолжил»** (Расход) $\rightarrow$ создание открытого долга *«Мне должны»*.
  - 📥 **«Вернули долг»** (Доход) $\rightarrow$ автоматическое погашение долга, который вернули вам.
  - 📥 **«Долг нужно вернуть»** (Доход) $\rightarrow$ создание открытого долга *«Я должен»*.
  - 📤 **«Вернул долг (я)»** (Расход) $\rightarrow$ погашение взятого ранее займа.
- **Умное распознавание контрагента:** Имя должника/заёмщика автоматически извлекается из поля заметки (`note`) с очисткой служебных префиксов.
- **Быстрые подсказки:** При выборе долговой категории в форме добавления появляются кликабельные бейджи с именами активных должников.
- **Синхронизация со счетами:** При погашении или выдаче долга из Планов баланс реального счета обновляется автоматически, а операция получает правильную категорию.

### 🎯 3. Планирование и Импорт выписок
- **Финансовые цели / Копилки:** Постановка целей с дедлайнами, кастомными цветами и иконками, отслеживание прогресса накоплений.
- **Регулярные подписки и платежи:** Учет периодических расходов (ежемесячно, еженедельно, ежегодно), виджет «Ближайшие платежи» на Главной с проведением оплаты в 1 клик.
- **Импорт банковских выписок:** Загрузка истории транзакций из файлов Excel (`.xlsx`) и `.csv` с гибким маппингом колонок и пакетным внесением в базу.

### 🤖 4. Мультимодальный AI (Google Gemini 2.5 Flash)
- **Сканирование чеков (Vision):** Фотографируйте или загружайте чеки/скриншоты оплат. Клиентское сжатие через Canvas мгновенно передает оптимизированное изображение в Gemini Vision, которое извлекает сумму, дату, время и категорию.
- **Голосовой ввод в браузере:** Встроенное распознавание русской речи через Web Speech API прямо в окне добавления транзакции.
- **Умный текстовый ввод (Smart Input):** Понимание свободной речи (*«вчера на базаре потратил 250 тысяч на мясо»*).
- **AI-Аналитик и стратегии:** Персональные рекомендации по оптимизации бюджета с учетом выбранной финансовой стратегии (50/30/20, 15/25/50/10) и темпа трат (Burn Rate).
- **Telegram-бот:** Ввод расходов текстом и голосовыми сообщениями через Telegram, озвучка финансовых отчетов через Google Cloud Text-to-Speech (`OGG_OPUS`).

### 🔒 5. Безопасность и Приватность
- **App Lock (Блокировка экрана):** Защита доступа к приложению по 4-значному PIN-коду (хэширование SHA-256) и биометрии (Face ID / Touch ID через WebAuthn).
- **Автоблокировка:** Автоматическая блокировка экрана при нахождении приложения в фоновом режиме более 2 минут.
- **BYOK (Bring Your Own Key):** Gemini API ключ хранится локально в `localStorage` пользователя.
- **Cloud Firestore Security Rules:** Строгие правила безопасности с разделением доступа по `userId` для коллекций `transactions`, `accounts`, `categories`, `goals`, `debts`, `subscriptions`, `userSettings`.
- **Fail-Safe Web SDK Config:** Наличие резервной публичной конфигурации Firebase Web SDK исключает белый экран при сборках без `.env`.

### ⚡ 6. Производительность и Архитектура
- **Офлайн-кэш IndexedDB:** Использование `persistentLocalCache` с многовкладочным менеджером (`persistentMultipleTabManager`) для мгновенного отклика интерфейса без ожидания сети.
- **Оптимизация $O(N+M)$:** Синхронный расчет балансов счетов за один проход по массиву операций.
- **Code-Splitting & Manual Chunks:** Динамическая ленивая загрузка маршрутов (`React.lazy`) и тяжелых библиотек (`xlsx`, `jspdf`, `html2canvas`). Размер основного бандла уменьшен с **1.75 МБ** до **~85 КБ** (gzip: ~25 КБ).
- **PWA (Progressive Web App):** Поддержка установки на экран смартфона, Service Worker для мгновенной загрузки.
- **Симметричная навигация:** Адаптивная мобильная нижняя панель с акцентной центральной кнопкой добавления `+` и быстрым доступом к планам.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript, Vite 5, React Router v6
- **Стилизация:** Чистый CSS3 (Modern Glassmorphism), Lucide React иконки
- **База данных & Бэкенд:** Firebase (Authentication, Cloud Firestore, Firebase Hosting, Cloud Functions v2)
- **AI:** Google Gemini API (`gemini-2.5-flash`), Google Cloud Text-to-Speech
- **Безопасность:** Web Authentication API (WebAuthn / Passkeys), Web Crypto API (SHA-256)
- **Утилиты:** `date-fns`, `xlsx`, `jspdf`, `jspdf-autotable`, `html2canvas`

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/durbek93/FinTracker.git
   cd FinTracker/tracker-app
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Переменные окружения (`.env`):**
   Создайте файл `.env` в папке `tracker-app`:
   ```env
   VITE_FIREBASE_API_KEY=ваш_api_key
   VITE_FIREBASE_AUTH_DOMAIN=ваш_проект.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=ваш_проект
   VITE_FIREBASE_STORAGE_BUCKET=ваш_проект.firebasestorage.app
   VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_sender_id
   VITE_FIREBASE_APP_ID=ваш_app_id
   VITE_GEMINI_API_KEY=опционально_глобальный_ключ
   ```

4. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```

5. **Сборка и деплой в Firebase:**
   ```bash
   npm run build
   npx firebase-tools deploy --only firestore:rules,hosting
   ```
